## Notes:
- **Transparent Backgrounds:** Device images (`pro-*.png` and `pro-max-*.png`) should ideally have a transparent background so they blend seamlessly with both dark hero sections and clean light card backgrounds.
- **Center Alignment:** Align the phone vertically and horizontally centered with uniform padding across all color variants so switching colors produces a smooth, non-jumping visual transition.
- **Graceful Fallback:** While these files are missing, the UI displays a clean, responsive placeholder box indicating the expected file path.
